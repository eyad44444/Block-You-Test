# بلوك يو تيست

كويز بين الصحاب: اعمل أسئلة عن نفسك، ابعت اللينك لصحابك، وشوف مين عارفك. النتايج بتظهر عندك لوحدها.

## الملفات
- `public/index.html`: الصفحة.
- `server.js`: السيرفر (Node من غير مكتبات غير `pg`).
- `handler.mjs`: الـ API وحساب الدرجة والشفرة السرية.
- `pgstore.mjs`: التخزين في قاعدة Postgres.
- `render.yaml`: بيعمل على Render الموقع والقاعدة مع بعض.

## النشر على Render (خطوتين)

### ١) ارفع الملفات على GitHub
Render بيستلم الكود من ريبو Git، ومفيش رفع ملفات مباشر.
1. اعمل Repository جديد على github.com اسمه `block-you-test`.
2. ادوس **uploading an existing file**، وسحب كل الملفات والفولدرات بعد فك الـ zip (`public` و`server.js` وباقي الملفات)، وادوس Commit changes.

الملفات لازم تبقى في أول الريبو، مش جوه فولدر `block-you-test`.

### ٢) اربطه بـ Render
1. سجل في render.com بحساب GitHub.
2. اختار **New ← Blueprint**، واختار الريبو، وادوس **Apply**.
3. Render بيعمل قاعدة بيانات `block-you-test-db` والموقع `block-you-test` ويربطهم لوحده.
4. بعد دقايق افتح الموقع من لينك `onrender.com` اللي هيظهر في الـ Dashboard.

في اللوج (Logs) لازم تلاقي سطر `storage: postgres`.

## حدود الخطة المجانية على Render (من docs.render.com/free)
- الموقع بينام بعد ١٥ دقيقة من غير زيارات، وأول فتحة بعده بتاخد حوالي دقيقة.
- قاعدة Postgres المجانية **بتنتهي بعد ٣٠ يوم** من إنشائها، وبعدها ١٤ يوم لو مرقيتهاش تتمسح بكل بياناتها. لو عايز كويزاتك تفضل، رقّيها لخطة مدفوعة، أو انسخ بياناتك قبل التاريخ ده.
- ٧٥٠ ساعة تشغيل مجانية في الشهر.

## الشفرة السرية
لو الصاحب كتب الاسم `IUXP` كل إجاباته بتتحسب صح. موجودة في أول `handler.mjs` (`SECRET_NAME`) وبتتحسب على السيرفر، فمش بتظهر في كود الصفحة.
